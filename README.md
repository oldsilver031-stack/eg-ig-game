# EG@IG 연구 페이지 (시험판)

AI 개입 정도에 따른 이미지 진위 판별률 측정 연구의 참가자용 웹 페이지입니다.

- `index.html`, `app.js`, `style.css`: 참가자 화면 (설명문·동의 → 지시문 → 연습 → 본 문항 → 설문 → 결과)
- `config.js`: 서버 주소(`API_URL`)와 시험판 표시 설정
- `versions.json`: 버전별 이미지 목록 (정답 정보 없음)
- `img/`: 자극 이미지 (무작위 파일명, 1024×1024, 메타데이터 제거)
- `apps_script/Code.gs`: Google Apps Script 서버 코드 (버전 배정, 응답 저장, 서버 채점)
- `credits.html`: 이미지 출처와 라이선스

정답표는 저장소에 올리지 않고 Google 스프레드시트의 `key` 시트에만 둡니다.
현재 이미지는 사전 테스트용이며 실제 연구 자료로 쓰지 않습니다.
